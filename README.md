# Sovereign Systems & Frontier Engineering Agent Harness

## Overview
This repository contains a dynamic, generative skill architecture for AI agents (Cursor, Claude Code, Gemini, or custom LangGraph harnesses). Instead of storing static textbook documentation, these files function as **procedural control engines** that sample variables from domain matrices to create unique, non-repetitive briefings and diagnostic audits.

---

## Gemini Integration
The core generative skills have been created and registered directly inside Gemini:
1. `dach-sovereign-infra`
2. `docker-k8s-infra`
3. `ai-token-compute-economics`
4. `regional-gtm-mechanics`
